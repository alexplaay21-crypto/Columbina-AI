## 2. Архитектурная карта (после изменений)

```
Telegram (aiogram) ─ telegram/bot.py ─ реестр COMMANDS · /settings → telegram/menu.py (inline-навигация)
        │  восприятие: media/processors.py + perception/vision.py (зрение для «слепых» моделей)
        ▼
cognition/engine.py — один ход разговора:
   PERCEPTION  appraisal.py (сарказм, флирт, удивление, опасность, обида на игнор, смена темы)
   REFLECTION  memory/retrieval.py (эпизоды, факты, биография по стадии) + inner/life.context_bits
   EMOTION     emotion/model.py (15 эмоций, инерция, затухание, ритм суток и луны)
   ACTION      один запрос к модели с единым «внутренним контекстом» → ответ / вопрос / реакция /
               инструменты (leave_note, web_search, read_url, http_get) → проверка характера
        │ после ответа (фон): reflection.py → факты, эпизоды (без дублей), темы, пояс, дневник
        ▼
memory/store.py (PostgreSQL / SQLite) · memory/maintenance.py (гигиена раз в сутки)
initiative/ (первые сообщения) + inner/life.py (исследования, сны, цели) — по планировщику, в бюджете
llm/ — OpenRouter / любой OpenAI-совместимый (Gemini, Groq) / Anthropic; ChainProvider, RoutingProvider
web/ — поиск (Tavily, Brave, Jina, SearXNG, DuckDuckGo, Wikipedia), чтение (Jina Reader), открытые API
```

Почему не 14 классов из ТЗ: у каждого существующего модуля уже одна ответственность. Добавлены только те, у
которых появилась новая работа: `InnerLife` (любопытство, исследования, сны, цели, дневник), `WebTools`
(инструменты), `VisionAdapter` (зрение), `Maintenance` (гигиена памяти), `MenuController` (меню),
`ChainProvider`/`RoutingProvider` (надёжность API). PersonalityEngine = ядро + `StyleGuard`,
DecisionEngine = appraisal + импульсы + выбор инструментов самой моделью — отдельный класс-обёртка
добавил бы дорогой лишний запрос на каждое сообщение.

## 3. Что реализовано

**Личность и естественность.** Ядро на каноне Genshin (Kuutar, Hiisi, Frostmoon Scions, Фатуи, Предвестники,
божественная природа). Своё мнение, спор, ирония; без обращения по имени в каждом ответе, без списков
и услужливых фраз; эмодзи редко (👀 при удивлении). 12 новых фрагментов о ней самой с пометками
«канон / интерпретация / проект». Медленная романтика по стадиям дружбы, без цепкости и ревности,
без откровенных сцен. Немного обижается, если писала первой и долго не было ответа. 2–3 сообщения
подряд, ответ «реплаем», реакции на события. Защита характера: подсказка, если начинает звучать как ассистент;
перегенерация при фразах ассистента, зависимости или шантаже.

**Эмоции.** Добавлены удивление, задумчивость, тревога; новые события: флирт, сарказм, глубокий вопрос,
опасность, игнор её сообщения, долгий разговор. Состояние сохраняется между перезапусками.

**Интернет.** Модель сама решает, искать ли (tool calling). До 3 запросов за раз, чтение страниц,
открытые JSON-API; лимиты на ответ (4 поиска, 3 страницы, 3 API) и в сутки; не больше 5 кругов
инструментов; SSRF-защита до любого запроса (включая Jina); содержимое сайтов помечено как недоверенное;
источники — отдельным сообщением. `WEB_ENABLED=false` выключает всё.

**Внутренняя жизнь.** Интересы (стартовые + из разговоров + из чтения), самостоятельные исследования
по 2 в сутки (2 поиска, 2 страницы, лимит токенов и 2 минуты), журнал знаний с источниками и
достоверностью (факты без реального источника отбрасываются), дневник (события, разговоры, открытия, сны),
сны только ночью по времени собеседника и не чаще раза в 3 дня, цели (завершаются или отпускаются через 14 дней).
Находками делится один раз; в разговоре знает, что действительно делала.

**Команды.** 8 основных в меню Telegram, ещё 27 работают при вводе; `/settings` — 8 разделов с подменю,
«Назад», редактирование одного сообщения, подтверждения для сброса разговора и удаления данных,
резервная копия и экспорт файлом, защита от повторных нажатий, настройки сохраняются в БД.

**Надёжность и расходы.** Запасная модель и запасной сервис целиком (`SECONDARY_*`), отказ от долгого
ожидания при перегрузке, лимиты денег (на собеседника и на весь бот), лимит запросов в сутки,
лимит фоновых запросов, гигиена памяти, healthcheck Docker через heartbeat планировщика.

## 5. Миграции

Новые таблицы `web_log, interests, knowledge, diary, goals, research, user_settings` создаются при старте
(`CREATE TABLE IF NOT EXISTS`) в SQLite и PostgreSQL. Существующие таблицы и столбцы не менялись —
воспоминания, факты и эмоции сохраняются. Ручных шагов не нужно.

## 6. Тестирование

- 184 автоматических теста на SQLite, 255 вместе с повтором на PostgreSQL 16 — все проходят.
- Покрыто: личность и канон, реакции, ответы «реплаем», обида на игнор, романтика по стадиям, зрение и PDF,
  часовой пояс, интернет (все поисковики, чтение, API, SSRF, лимиты, цикл инструментов), исследования и бюджет,
  дневник, сны, цели, находки в инициативе, все команды и каждый раздел меню, переключатели после
  «перезапуска», подтверждения, файлы, сквозной прогон через настоящий Dispatcher aiogram, слияние
  воспоминаний, противоречия фактов, гигиена памяти, контроль расходов, параллельные сообщения,
  перезапуск, ошибки API.
- Вживую (с вашими ключами Groq и Gemini): ответы за 1–4,5 с, фото через описание Gemini, поиск
  курса валют с источником, исследование по реальным страницам Wikipedia через Jina, Docker + PostgreSQL.
- Из этой песочницы DuckDuckGo отдавал капчу, а Wikipedia — 429 (общий IP). На VPS обычно работают;
  если нет — помогает бесплатный ключ Tavily или Brave.

## 7. Что пока не реализовано

- Голосовые ответы и кружки от неё (TTS): нужен выбор синтетического голоса; Groq TTS только английский.
- Отправка ею стикеров, GIF и фото (она их понимает, но сама отправляет только текст и реакции).
- Мелодия колыбельной и кто её пел; проверка спорных соответствий канона в `canon.yaml` (помечены `check`).
- Автоперезапуск по healthcheck (обычный docker compose только помечает контейнер unhealthy).

## 8. Расход дополнительных токенов

| Что | Токенов | Когда |
| --- | --- | --- |
| Описания инструментов в каждом ответе | ~700 входа | всегда, если интернет включён (у Claude кэшируется) |
| Внутренняя жизнь в контексте | 100–300 входа | всегда |
| Ответ с интернетом | +1–2 запроса по 2–6 тыс. входа | только когда она решила искать |
| Исследование | ~7 тыс. входа + ~1 тыс. выхода | до 2 раз в сутки |
| Сон | ~800 | раз в 3 дня |
| Описание фото | ~1,5 тыс. | на каждое фото у «слепой» модели |

На бесплатных Groq + Gemini — $0, но это тратит их лимиты. На Claude Sonnet 5.5 через OpenRouter —
примерно +$0,05–0,15 в день к обычному общению.

## 9. Обновление и перезапуск на VPS

```bash
cd ~/Columbina-AI            # папка проекта
git pull origin main
docker compose up -d --build
docker compose logs -f bot   # первая строка: LLM: … storage: postgres
```

Затем в Telegram: `/check` (админ) и `/settings`.
