### Добавлено сверх ТЗ (полезное)
- **«Записки сквозь время»** — напоминания через инструмент `leave_note`. Это интерпретация её канонической способности «Отражение Луны».
- **Точная фаза луны без API**: астрономический расчёт, погрешность — минуты. Её «лунное чувство» опирается на правду.
- **Реальные признаки голоса** через ffmpeg (темп, паузы) — без выдуманной «интонации».
- **Её собственная жизнь запоминается**: что она рассказала о своих духах и пирогах, не будет противоречить само себе.
- **Защита от провалов**: refusal-fallback на сервере, «бледный» ответ при сбое API или превышении дневного лимита.
- **Прозрачность и приватность**: `/memory` показывает, что она помнит, `/forget да` стирает всё.
- **`/hall`**: состояние без чисел, через цвет цветов в Серебряном Зале.
- **Список допущенных пользователей и `/stats`** для администратора: контроль расходов.
- **Безопасность важнее образа**: при признаках кризиса стилизация отключается.

## Что осталось / не проверено

1. **Живой прогон не выполнялся.** В этом окружении нет `ANTHROPIC_API_KEY` и токена Telegram. Код провайдера проверен на сборке параметров. Нужно запустить `python -m evals.run_evals` с ключом, прочитать провалы и подстроить `core_prompt.md` (это займёт 1–3 итерации).
2. **Распознавание речи** требует ключа Whisper-совместимого сервиса: OpenAI, Groq или локального. Без него голосовые честно помечаются как «не расшифровано».
3. **Звук помимо речи** (музыка, шумы) не анализируется, так как нет подходящего API. Она знает только слова, длительность, темп и паузы.
4. **Голос Коломбины (TTS)**: не сделано. Досье запрещает клонировать голос актрисы. Нужен синтетический голос, выбор за автором.
5. **Авторские пробелы \[Р\]**: колыбельная теперь есть (`data/persona/lullaby.yaml`); её мелодия и то, кто её пел, а также русские словесные игры, «крылатые» фразы и имена мира пока открыты.
6. **Масштаб**: PostgreSQL готов. Для очень большого числа пользователей стоит перейти с long polling на webhook и запускать несколько воркеров.
7. **Групповые чаты** намеренно не поддерживаются (только личные).
8. **Деплой**: Docker Compose готов; CI и автоматические бэкапы по расписанию не настроены.

## Какие API используются

| API | Для чего | Обязателен |
| --- | --- | --- |
| Telegram Bot API (aiogram 3) | общение | да |
| Anthropic Messages API: `claude-opus-5-5` | основной ответ, инициатива | да |
| Anthropic Messages API: `claude-haiku-5-5` | рефлексия, суммаризация (структурированный JSON) | да |
| Whisper-совместимый STT (OpenAI `gpt-4o-mini-transcribe` / Groq `whisper-large-v3-turbo`) | голосовые, звук видео | нет |
| Voyage AI `voyage-3.5-lite` | эмбеддинги памяти (лучше локальных) | нет: есть бесплатный локальный |
| Open-Meteo | погода и часовой пояс по городу | нет, бесплатно, без ключа |

Функции Anthropic API: prompt caching (ядро на 1 ч, история на 5 мин), mid-conversation system message для динамического контекста, adaptive thinking с `effort: low`, структурированные выходы (`output_config.format`), tool use (`leave_note`), vision, PDF, серверный `fallbacks: "default"` на случай отказа классификатора.

Сменить провайдера можно, реализовав `LLMProvider.complete()` (`columbina/llm/base.py`). Остальной код от провайдера не зависит. Модели меняются в `.env`: `MAIN_MODEL`, `BACKGROUND_MODEL`.

## Расход токенов (оценка)

Основной запрос (по `scripts/token_report.py` и структуре запроса):

| Часть | Токенов | Тариф |
| --- | --- | --- |
| Ядро + инструмент | ~2 250 | чтение кэша (0.05× цены входа) |
| История (≤40 сообщений) | 0,5–2 тыс. | в основном чтение кэша |
| Новое сообщение + внутренний контекст | ~500–900 | обычный вход |
| Ответ + адаптивное мышление (`low`) | ~150–400 | выход |
| Фото | ~1 200–1 600 | обычный вход |

Фон на Haiku 5.5: ~1,5 тыс. входа и ~250 выхода на ход. Резюме — раз в ~8 ходов.

## Сколько стоит один день

«Обычное использование»: ~60 сообщений в день (≈45–50 ходов после склейки подряд идущих), 3 фото, 5 минут голосовых, 1–2 инициативы, 2–3 «сессии» с перерывом больше часа (кэш ядра пишется заново).

| Основная модель | Ход | День (обычный) | День (активный, ~200 сообщ.) | Месяц (обычный) |
| --- | --- | --- | --- | --- |
| **Claude Opus 5.5** (по умолчанию) | ~$0,009–0,015 | **≈ $0,6–0,9** | ≈ $2–3 | ≈ $18–27 |
| Claude Sonnet 5.5 | ~$0,005–0,008 | ≈ $0,3–0,45 | ≈ $1–1,5 | ≈ $9–14 |
| Claude Haiku 5.5 | ~$0,0004 | ≈ $0,03–0,05 | ≈ $0,15 | ≈ $1–1,5 |

Сюда уже входят фон (~$0,01/день), фото (~$0,02), STT (~$0,015 у OpenAI `gpt-4o-mini-transcribe`) и Voyage (меньше цента). Open-Meteo бесплатен.

Фактический расход виден в `/stats` (администратор) и в таблице `usage`. Защита от перерасхода: `DAILY_BUDGET_USD_PER_USER` (по умолчанию $3) и `ALLOWED_USER_IDS`.

Рекомендация: начать с Opus 5.5 на `MAIN_EFFORT=low`, прогнать evals. Если персонаж держится, попробовать `MAIN_MODEL=claude-sonnet-5-5`: это вдвое дешевле. Haiku 5.5 подходит для фона, но для основного голоса персонажа, скорее всего, слабее; это стоит проверить теми же evals.
