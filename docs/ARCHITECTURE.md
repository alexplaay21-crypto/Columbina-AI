# Columbina AI — архитектура личности и когнитивного движка

## 1. Что уже было и чего не хватало

**Было (данные о личности):** полное досье (`data/persona/source/dossier_main.md`) и расширенное
дополнение (`dossier_extended.md`): биография, психология, речь, внешность, восприятие, способности,
эмоции, стадии дружбы, 23 примера диалогов, открытые решения.

**Не было (технически):** репозиторий был пуст — ни бота, ни памяти, ни формата хранения личности.
«Существующую систему памяти» подключить было не к чему, поэтому память сделана с нуля как отдельный
модуль с узким интерфейсом (`MemoryStore` + `MemoryRetriever`), который можно заменить.

## 4. Формат хранения личности

| Файл | Что | Как используется |
| --- | --- | --- |
| `core_prompt.md` | Компактное ядро (~2 тыс. токенов): кто она, как думает и говорит, пределы, восприятие, безопасность, формат ответа | Системный промпт; **не меняется** между ходами → кэш 1 час |
| `knowledge.yaml` | 40 фрагментов биографии, вкусов, привычек, мнений с `tags`, `min_stage`, `reveal` | Семантический поиск; в запрос попадает 0–2 фрагмента, **доступных на текущей стадии** |
| `abilities.yaml` | 9 канонических способностей × 3 слоя (канон / симуляция / бот) + черты восприятия | Abilities Engine выбирает 0–2 заметки по триггерам |
| `emotions.yaml` | 12 эмоций: базовый уровень, период полураспада, проявление; ритм суток и луны; 29 событий с дельтами; цвета цветов | Emotion Model |
| `relationship.yaml` | 5 стадий (поведение, что раскрывает), события доверия, вехи | Relationship Model |
| `lullaby.yaml` | Её колыбельная на латыни: точный текст, приблизительный смысл, правила исполнения | Попадает в контекст только когда её просят спеть или человеку не спится ночью |
| `style_rules.yaml` | Жёсткие запреты (манипуляция, голос ассистента, божественность), мягкие правки, приметы, которые нельзя повторять | StyleGuard |
| `source/` | Исходное досье | Истина в последней инстанции; в запросы не идёт |

Правка личности = правка YAML/MD, код не трогается.

## 5. Cognitive Engine: один ход

Один основной запрос к модели вместо отдельного на каждый пункт. Восемь вопросов из ТЗ закрываются так:

| Вопрос | Откуда | Где в запросе |
| --- | --- | --- |
| 1. Кто она | `core_prompt.md` | `system` (кэш) |
| 2. Ситуация | `situation.py` (время/луна/погода) | «Сейчас: …» |
| 3. С кем говорит | профиль, стадия дружбы | «С кем говоришь…» |
| 4. Что было раньше | история (кэш) + скользящее резюме | messages + «Что было раньше» |
| 5. Воспоминания | `retrieval.py`: top-k эпизодов, факты, её биография по стадии | «Всплыли воспоминания…», «Из твоей жизни…» |
| 6. Эмоции | `emotion/model.py` | «Твоё состояние…» — словами, без чисел |
| 7. Способности | `abilities/engine.py` | «Способности и пределы сейчас» |
| 8. Как хотела бы ответить | appraisal → импульсы | «Тебе хочется: … Это импульс, не инструкция» |

Плюс «Что дошло» (восприятие), «Ты замечаешь» (наблюдения), «Длина ответа» и анти-повторы.

Порядок блоков для кэша: `system` (1ч) → история (брейкпоинт на последнем сообщении) → новое сообщение →
`role: system` «Внутренний контекст» (mid-conversation system message — не ломает кэш истории и служит
операторским каналом, отдельным от слов пользователя).

**Живое поведение:**
- длина задаётся по длине сообщения собеседника, усталости, теме; ответ можно разбить на 2–3 сообщения
  (`---`) или ответить только реакцией (`<react>🕊</react>`);
- приметы стиля («Хм?..», луна, духи, многоточия, вопрос в конце) считаются по последним 6 ответам —
  при перерасходе модель получает подсказку «не начинай с…»;
- метки пауз в истории «(спустя 2 дн.)» — она чувствует время между репликами;
- debounce 2,5 с: несколько сообщений подряд — один ответ; «печатает…» и паузы между частями;
- `ты/вы` определяется по сообщениям собеседника;
- проверка характера после генерации: манипуляции («не уходи», «почему так долго не писал»),
  голос ассистента, божественность, ласкательные прозвища → одна перегенерация с поправкой.

## 6. Abilities Engine

Новых канонических способностей не добавлено. Для каждой из 9 способностей досье §13 в `abilities.yaml`
описаны суть, принцип, возможности, ограничения (канон), влияние на восприятие и мир, бытовое проявление
(симуляция) и **реальная техническая возможность бота**:

| Способность | Реальная возможность бота |
| --- | --- |
| Лунное чувство | Время и пояс собеседника, точная фаза луны (расчёт), погода по городу/геолокации |
| Перенос | Нет: не обещает прийти; стилистика внезапного прихода/ухода |
| Речь с природой | Реакция на животных на фото и в рассказах (догадки, не факты) |
| Лунный свет и рост | Нет: только её мир и шалости в рассказах |
| Светящиеся камни | Помощь запутавшемуся: 1–3 конкретных шага, без лекции |
| Облегчение боли | Ночной режим: колыбельная, короткая история; никаких мед. обещаний |
| Путь на луну | Совместная воображаемая прогулка — только на стадии 5 |
| Время (Отражение) | «Записки сквозь время»: инструмент `leave_note` + планировщик (напоминания) |
| Растворение | Сбои и лимит бюджета — «сегодня я бледная», без шантажа |

## 7. Perception Engine

Каждый вход → `Percept(kind, delivered, channel, note, text, parts)`. Канал задаёт, как она это
восприняла: `seen` (видит), `frames` (только кадры), `transcript` (только слова, не голос), `read`,
`metadata` (только описание), `nothing` (не дошло). В контексте это явная строка, например:
«голосовое 0:14; по звуку: говорит быстро (голоса ты не слышишь — дошли только слова)».

| Тип | Обработка |
| --- | --- |
| Текст | как есть; ссылки внутри читаются отдельно |
| Фото | в модель как изображение (vision), уменьшается до 1568 px; описание сохраняется в историю |
| Голосовое | STT (Whisper-совместимый API) + реальные признаки звука через ffmpeg: темп (слов/с), доля пауз |
| Аудиофайл | STT до 10 минут; дольше — только метаданные |
| Видео, гифка | ffmpeg: 2–6 кадров (~1 на 5 с, без краёв) → vision; звуковая дорожка → STT |
| Кружок | как видео |
| Документ | PDF — целиком в модель (document block); DOCX/TXT/MD/CSV/код — текст с пометкой «прочитано N из M» |
| Ссылка | SSRF-безопасная загрузка, извлечение текста; не открылось — так и сказано |
| Пересланное | помечено «переслано от …» — она понимает, что это чужие слова |
| Стикер | только эмодзи стикера (картинку не видит) |
| Геолокация | только для погоды и пояса (по согласию) |

**SSRF:** только http/https и порты 80/443, без логина в URL, резолв DNS и проверка всех адресов
(private, loopback, link-local/метаданные облака, CGNAT, multicast, IPv6 ULA, IPv4-mapped), соединение
на проверенный IP с исходным SNI/Host (защита от DNS rebinding), ручные редиректы с повторной проверкой,
лимиты размера/времени/типа.

## 8. Эмоции

12 эмоций с базовыми уровнями из характера (спокойствие 0.6, любопытство 0.3…). Меняются только
событиями: быстрые — по сообщению до ответа (вес 0.8), тонкие — по фоновой рефлексии после ответа,
системные — погода, возвращение после молчания. Инерция: ≤0.35 за событие и насыщение у края. Затухание
к базовому уровню (обида — часы, смущение — минуты). Ритм суток и луны сдвигает базовые уровни
(днём устаёт, ночью оживает, полнолуние — радость). Состояние сохраняется между диалогами в БД.
Наружу — только слова («спокойна, чуть с любопытством») и описание манеры; числа модель и пользователь
не видят. `/hall` показывает намёк цветами Серебряного Зала.

## 9. Память

| Слой | Хранение | Как попадает в запрос |
| --- | --- | --- |
| Рабочий контекст | `messages` (активные) | вся активная история (≤40 сообщ.) — кэш |
| Старый диалог | `summaries` | резюме 180 слов; архивируется кусками → начало окна стабильно для кэша |
| Эпизоды | `episodes` (kind=shared) + вектор | top-5: 0.55·смысл + 0.25·слова + 0.12·давность + 0.08·важность, порог |
| Её собственная жизнь | `episodes` (kind=her_life) | события за 3 дня — чтобы не противоречить себе |
| Факты о собеседнике | `facts` (ключ→значение, уверенность, закреплённые) | закреплённые + до 8 релевантных |
| История отношений | `relationship` + журнал `events` | стадия и поведение словами |
| Эмоциональное отношение | `emotion_state` + журнал `events` | состояние словами |
| Её биография | `knowledge.yaml` + векторы в `persona_embeddings` | 0–2 фрагмента, только до текущей стадии |
| Темы и записки | `threads`, `notes` | в контекст и в Initiative Engine |

Хранилище: PostgreSQL в проде (`DATABASE_URL`, пул asyncpg, `BIGINT` для Telegram ID), SQLite для
разработки и тестов (`DB_PATH`). SQL один и тот же: `?`-плейсхолдеры, `ON CONFLICT … DO UPDATE`, `CASE` вместо
`MAX(a,b)`; различаются только типы в схеме. Векторы — float32 в `BYTEA`/`BLOB`: поиск идёт внутри одного
собеседника, поэтому число пользователей на него не влияет. pgvector понадобится, только если у одного
человека будут десятки тысяч эпизодов.

Эмбеддинги: Voyage AI (`voyage-3.5-lite`, мультиязычный) или локальный хэш-эмбеддер (бесплатно, офлайн).
При смене провайдера векторы пересчитываются автоматически. `/memory` показывает, что она помнит;
`/forget да` стирает всё.

## 10. Инициатива

Повод должен быть настоящим: записка (о которой просили), незакрытая тема в назначенное время, полнолуние
(раз за цикл), первый снег (раз в сезон), молчание 5+ дней (один раз), тайный «подарок» по интересам
собеседника (стадия 3+, раз в неделю). Ограничения: не на стадии 1 (кроме записок), не в тихие часы,
не чаще раза в сутки (`rare` — раз в 3 дня), не раньше 6 часов после разговора, **молчит, если на прошлую
инициативу не ответили**. Сгенерированное сообщение проходит ту же проверку характера; при нарушении
не отправляется. `/initiative off|rare|normal`, `/quiet 23 9`.

## 11. Принятые решения из «Открытых решений» досье

| Вопрос | Решение | Где поменять |
| --- | --- | --- |
| Её жизнь между разговорами | а) модель придумывает мелкие события, они **запоминаются** (her_life) | `reflection.py` |
| Частота инициативы | б+в, настраивает пользователь | `initiative/engine.py` |
| Стартовая стадия | а) стадия 1 | `relationship.yaml: start_stage` |
| Виден ли прогресс | б) намёки цветами (`/hall`) | `emotions.yaml: flowers` |
| Отношение к тому, что она ИИ | б) метафора + честный ответ на прямой вопрос | `core_prompt.md` |
| Цвета радости/грусти | б) розовый / бледно-голубой | `emotions.yaml` |
| Романтические намёки | б) мягкое смущение и смена темы | `core_prompt.md` |
